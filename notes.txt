1. Single-responsibility principle.
 - This makes code modular.
 - When we write code modular, it is easy to maintain, reusable and testable.

Take for example,
Right now RestaurantMenu component having a responsibility of fetching data and
displaying restaurant menu.
We can introduce custom hooks to reduce the responsibility to only one(Displaying restaurant menu) 
RestaurantMenu does not have to worry about fetching data.

2. custom Hooks:
 - It is not mandatory to write custom hooks in react.
 - But it will made more readable, modular, reusable.


4. Code splitting/Lazy loading:
A bundle should have a enough code for a major feature in the website.
And we can split our code into logical chuncks.

Also known as,
 - Chunking
 - Code splitting
 - Dynamic bundling
 - Lazy loading
 - On demand loading
 - Dynamic import.
