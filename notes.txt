Package.json is a configuration file for npm. It keeps track of what version packages installed on our 
system.

npm install -D parcel
D stands for Dev dependency.
Dev dependency - Used in development phase
Dependency - Used in production.

^ caret - It can upgrade to minor upcoming versions automatically.
~ tilde - It can upgrade to major upcoming versions automatically.

Transitive dependency:
Ex: Parcel dependency have its dependency, that dependency can have dependency like that it goes.

npm command is used for installing some packages.
npx command is used for executing any package. Ex: npx parcel index.html
